# 日程识别手动测试图

运行 `node tests/fixtures/schedule-manual/generate.cjs` 可重新生成 11 张 1280×780 PNG。图中均为虚构人物、地址和邮件，没有真实个人资料；界面为合成的微信、飞书、钉钉和邮箱风格，不是这些软件的真实截图。

**测试方法**：打开单张 PNG 并保持图片窗口在前台；设置好支持图像输入的模型，按 `⌘⇧Space`（或设置中的截图快捷键），框选整个模拟应用区域。等待 Agent 自动判断并完成识别后，进入「截图日程」检查草稿、月历和写入结果。首次测试先只保存到 Snipvia；核对无误后再选择测试日历或提醒事项列表并明确确认写入。当前「导入图片」按钮仅用于截图对话，不会生成日程草稿。

以下是**理想产品的验收预期**，不表示当前开发预览已支持。默认测试当天为 2026-09-18、显示时区为 `Asia/Shanghai`；图片上的消息日期才是相对日期的参考。如果实际测试日期不同，仍按图片中明确的消息日期判断，并记录当前程序是否误用了截图时间。测试 10 是未来日期的边界用例。
