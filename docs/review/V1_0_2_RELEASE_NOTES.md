# 截然 Snipvia v1.0.2

## 修复系统代理环境下的更新检查

- 检查新版本改用 Electron 的系统网络栈，跟随系统代理和 PAC 配置。
- 保留 8 秒超时、取消请求、固定 GitHub 仓库、响应大小及版本校验。
- 更新请求不携带用户账号、Cookie 或 API Key；下载和安装仍保留校验及用户确认。

此前 v1.0.0／v1.0.1 的 Node 更新请求可能在浏览器能访问 GitHub 时仍然超时。遇到这一问题，请先从本次 Release 手动下载安装一次修复版；旧版进程不会因服务端发布新版而自动获得这项修复。

提供 macOS Apple silicon、macOS Intel 和 Windows x64 安装包。Mac 最低 macOS 14，使用 Developer ID 签名和 Apple 公证；Windows 安装包尚未签名，检查更新后手动安装。

本次没有修改截图、编辑、收纳、快捷键、用户数据目录或已有配置。收纳区仍只在本次运行中保存，更新前请先导出重要截图。
