# 验证与结果复用

只对实际变化执行必要验证，不为生成报告重复跑已通过且输入未变的检查。失败、跳过和未执行不能写成通过。

| 变化 | 所需检查 |
| --- | --- |
| 文档、未被构建引用的原型 | Markdown 链接、脚本输入引用、业务文件哈希及恢复清单 |
| 类型、配置、存储或 IPC | lint、typecheck、相关单测；涉及窗口/旧数据时 Electron 回归 |
| 截图或原生能力 | 核心单测、窗口回归、必要的轻量真机样本 |
| 依赖或打包配置 | 锁文件一致性、构建与相关打包工具检查 |
| 已冻结产物再次上传 | 核对相同 hash 的既有验收，不复用到不同字节的包体 |

默认测试不访问真实用户数据或模型。实际录屏单独 opt-in，不自动运行 500/1000 次负载；平台未验收保持待验。

release:prepare 的本地指纹与构建复用只适用于相同输入/输出；文档更改不代表源码曾重新测试。签名、公证、正式 Release 和推送需要独立授权。本轮 A→D 清理改变了配置、契约、原生 OCR 和依赖，已重新运行受影响检查；未复用前一轮“只改文档”的业务验证结论。详细命令、数量和未验范围见 [清理记录](review/CLEANUP_REVIEW.md)。
