# 当前 V2 数据与网络边界

## 截图和本地输出

完整屏幕帧仅供框选，在完成或取消后释放；当前截图链路不上传图片。Quick 写系统剪贴板，Edit 只在用户保存时写目标文件，Collect 在本次运行内保存有界临时字节。合并复制同样进入系统剪贴板；其他应用或系统剪贴板管理工具可能读取它。

Collection 关闭/隐藏后仍保留，退出或崩溃不恢复。PNG 导出写入用户选定位置下的新目录；保存的截图及原有本地历史并非加密图库。不要将“本地优先”理解为没有磁盘或剪贴板副本。

用户从展开列表拖出图片时，Main 才会把该图原始字节写入系统临时目录下的私有随机文件夹，并交给操作系统的原生文件拖放。目标应用可能读取或复制该文件。临时文件按 ID 复用，限制 128 项 / 256 MiB；闲置超过 30 分钟后在下一次拖出时清理，正常退出尝试清理本进程目录（目标仍占用时由系统临时目录机制清理）。崩溃后可能留下临时文件，由系统临时目录机制清理；这不是加密或持久图库。拖动不写入原用户历史、不上传图片，也不把任意磁盘路径暴露给 Renderer。

全部复制会将每张原图写入 userData/clipboard-files 下的私有随机批次目录，再将文件引用交给系统剪贴板，行为与文件夹多选复制相同，不合并、不上传。目录/文件权限为 0700/0600（Windows 依赖系统 ACL）；其他应用或剪贴板管理工具可以读取这些文件。为支持延迟粘贴，清空收纳或退出不会删除已复制批次；当前剪贴板引用的批次保留，其他批次超过 30 分钟在下次全部复制时清理，总量限制 512 MiB，空间不足会提示并保留原图。未再次复制时可能长期留存；这是未加密的本地副本，不是截图历史或备份。

## 设置与旧数据

V2 快捷键写入独立 capture-preferences.json；主题沿用 settings.json，只修改 appearance.mode，保留旧的未知字段、模型配置和密文。当前源码不再包含旧凭据解密、读写或迁移接口，不读取、删除或上传旧 Key。

旧 history、schedule 和 notebooks 索引在用户点击时只读读取，显式导出仅包含白名单索引及引用图片，不包含凭据文件。旧 Markdown 留在原目录。不要提交用户目录、笔记、截图、Key 或备份。

兼容读取不验证或解释旧模型和预测配置；这些数据原位保留，不能用于发起请求。异常外观数据拒绝覆盖。文件级变更见[清理记录](review/CLEANUP_REVIEW.md)。

## 网络

当前 V2 不调用账号、模型、Agent 或笔记服务。正式包可后台检查配置中的 GitHub Release；显式下载/重启才进入更新安装流程。外链仅允许安全 HTTP(S)，由 Main 检查并交给系统浏览器。更新不会发送截图、旧账号 Cookie 或模型 Key。

## 测试与排障

默认回归只用合成图片和临时用户目录。真实录屏 opt-in 不提交屏幕内容；分享日志或截图前自行脱敏。安全反馈渠道见 [SECURITY](../SECURITY.md)。

## 截图后快速切换条

此功能默认关闭。启用后，用户指定的应用身份和路径、网页地址及显示顺序单独保存在本机 userData/quick-target-preferences.json，不迁移或改写旧设置。应用图标和浏览器角标从本机读取。启用功能后，网站图标按下述边界从公开页面在后台读取并缓存。

选择条在 Quick 或收纳区单张复制、合并复制、全部复制成功后显示，复用同一个可关闭的快速切换设置。图片字节或全部复制的独立文件引用，与随机、无业务含义的会话标记在同一剪贴板提交中写入；启用且已添加目标时才增加标记。全部复制仍保留原图文件列表，不合并。显示期间仅检查此标记，不读取图片内容或其他应用的剪贴板文字，不将标记写日志。其他复制覆盖标记时选择条失效，不恢复或覆盖新内容。

点击应用只请求激活用户选定的本地应用，未允许启动时不启动未运行应用；点击网页由系统默认浏览器打开明确保存的 HTTP(S) 地址，该网页的网络访问遵循浏览器与网站自身规则。默认打开网址的路径不读取浏览器 Cookie、聊天正文、输入草稿或其他网站标签；不代替用户粘贴或发送截图。第一阶段不调用辅助功能或 Apple Events；第二阶段的可选 Chrome 模式边界见下文。截图字节不传给选择条 Renderer 或切换 helper。


### 可选的 Chrome 已有标签与聚焦

只有用户把网页目标改为「Chrome 已有标签」并选择目标时，才通过本机 Apple Events 匹配普通标签。脚本需要逐个读取普通标签地址来匹配保存的网址，只将匹配标签的地址、标题及原生引用返回 Main；隐身窗口不枚举。Renderer 只收到临时选择 UUID、标题与序号。会话标题可能包含个人信息，仅保存在当前内存会话，不写日志或配置文件。

辅助功能授权是独立可选项。启用聚焦时仅检查前台 Chrome 对应 WebArea 的角色、URL、可编辑状态及可见几何，寻找唯一多行编辑区；不读取 AXValue、输入草稿、聊天正文或 Cookie。不代用户粘贴、发送或输入，不读取截图字节。无法确定时不执行聚焦，网页切换成功后静默收起选择条。

查询权限状态不会主动请求授权；只有设置中的授权按钮请求，或固定的系统权限设置入口打开设置页。开发 App 的用途声明/签名迁移可能使既有录屏权限需要重新登记；系统权限不会随源码或 App 文件快照自动恢复。具体故障及验收边界见[第二阶段记录](v2/QUICK_TARGET_PHASE2.md)。

### 网站图标与浏览器角标

只有快速切换功能开启且存在网页目标时，Main 才会在后台读取目标网站的公开首页和声明的图标。只使用保存地址的 origin，不发送会话路径、查询参数或片段；不读取或携带浏览器 Cookie、登录态、Authorization、Referer、截图、剪贴板、旧 Key 或账号数据。公开首页可能将图标放在其他 CDN；对应站点/CDN 仍会收到请求 IP 和固定的 Snipvia-Website-Icon User-Agent。不会执行页面脚本或读取浏览器个人资料。

图标请求限制标准 HTTP(S) 端口，拒绝 URL 中的账号密码、回环、内网、链路本地及云元数据目标；重定向逐次检查，HTTPS 不降级。连接固定到已检查的 DNS 路由。为兼容当前网络中的透明 DNS 网关，域名解析得到的 198.18.0.0/15、2001:2::/48 虚拟路由按代理别名处理；直接填写这些 IP 的网址仍被拒绝。这种代理模式下，上游真实地址的解析由用户网络网关负责，客户端无法独立核实网关后的最终 IP。

首页最多 192 KiB、单张图标最多 256 KiB；有重定向、并发和时间预算限制。仅处理有界 PNG、支持的 ICO 栅格，不把网页 HTML、SVG 或脚本交给 Renderer 执行。下载图像缩放为最多 68px 的 PNG；Renderer 只收到本地数据，不放宽其 CSP。失败静默回退到内置或通用图标，不阻止截图、复制及切换。

衍生 PNG 缓存位于原有 userData/website-icons，目录/文件使用 0700/0600（Windows 依赖系统 ACL），文件名是 origin 的 SHA-256，内容仅有时间和小型图标，不保存首页、源图标 URL 或会话网址。成功缓存有效期 7 天，过期时先显示旧图再后台更新；失败在当前进程内退避 1 小时。最多处理 8 个已配置目标，并发最多 2 个。关闭功能会停止排队并取消请求，保留已有离线图标；已送达网站的请求无法撤回。浏览器角标显示 Chrome 已有标签模式或系统默认浏览器；系统浏览器图标最多在内存缓存 5 分钟，改变默认浏览器后下次设置刷新会重新读取。
