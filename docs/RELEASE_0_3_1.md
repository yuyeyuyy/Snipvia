# Snipvia 0.3.1 推送与打包记录

本次按用户确认使用补丁版本 0.3.1。工作区仅为 `Snipvia-public-baseline`，基线 `7527c01`；原目录、私有仓库和生产服务均未改动。既有 0.3.0 标签和安装包保留。

## 产品改动

- 笔记自动保存，保留选择范围、原子提交、差异和撤销；脚本及通用文件权限边界保留。
- 截图对话增加拖拽和键盘尺寸调节，紧凑与展开模式分别保留本次运行尺寸。
- 对话正文、代码和输入支持 12–24px 字号，设置跨窗口同步且重启保留。
- 设置分组标题、行标签和说明通过字号、字重与留白区分，保留黑白灰主题。

行为细节、实际截图和已完成测试见 [操作优化记录](CHAT_CONTROLS_2026_10_18.md)。

## 精简后的验收

复用已有 63 文件 / 988 单元测试、9 项 Electron 用例及 lint 结果，不因打包重复运行。新增打包工具单测 4 项及定向 lint 已通过。0.3.1 新构建包含类型检查、生产编译和 276 项生产依赖通知；缺失许可证文本为 0。

[验收复用规则](VALIDATION_POLICY.md) 与 [机器记录](ci/release-0.3.1-validation.json) 明确区分复用证据和本轮实际执行。两个平台的准备入口已实际输出 `Reuse verified desktop`，macOS 签名重试也复用 Native 构建；没有重复编译。新产物的签名、公证和完整性检查仍须分别完成。

## 兼容、安全与发布边界

应用标识 `com.snipvia.desktop`、实际用户数据目录和加密 Key 存储不变。新字号缺省 15px，本轮不需要迁移或删除数据。

Windows 真机、Intel 真机、混合 DPI、真实厂商模型与安装升级未在本轮补做。旧版本报告中记录的依赖告警没有因本次 UI/打包改动得到修复，详见 [依赖安全记录](opensource/dependency-security.json)。

本轮仅推送源码和生成本地安装包，不创建正式 Release、不改变仓库可见性、不停止服务。更新源仍为 `yuyeyuyy/Snipvia`；0.3.1 尚未成为在线更新。

## 恢复路径

包装前全部 52 项改动保存在忽略目录 `.dev-runtime/release-0.3.1/before-packaging.tar.gz`、二进制补丁和逐文件 SHA-256 清单中。恢复应先解到另一目录比对，不使用 reset、clean 或覆盖后续用户改动。打包重试使用独立时间戳目录，旧包仍可用。源码回退不删除本地笔记或用户设置。
