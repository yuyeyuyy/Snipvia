# V2 当前产品范围

Snipvia 是免费、无需登录、本地优先的截图、编辑与连续收纳工具。

## 已实现

- Quick 框选后直接复制，无贴图或历史会话。
- Collect 每次快捷键进行一次框选，追加到右上角 Shelf。
- Shelf 展开、收起、隐藏、数量反馈、图片预览、删除、拖拽/按钮排序及确认清空。
- 选中子集或全部，纵向合并复制、独立 PNG 导出；展开列表可拖出原图文件至支持文件拖放的目标。
- 原截图编辑器：标注、撤销、复制、保存及贴图。
- 自定义快捷键、主题、自启、权限引导、反馈群号复制。
- 可选的截图后快速切换条：用户固定应用/网页并排序，Quick 复制成功后无焦点显示；macOS 切换应用，网页使用默认浏览器打开地址。新增可选的 Chrome 已有标签匹配与多项选择，以及受限消息输入框聚焦；实现和合成测试见[第二阶段记录](v2/QUICK_TARGET_PHASE2.md)，用户已确认开发录屏恢复及 ChatGPT 跳转顺畅；真实网页输入框聚焦仍待单独验收。
- 旧记录只读查看与导出、旧截图显式导入。
- 独立 GitHub Release 更新模块。

## 产品边界

收纳仅在本次运行内保留，最多 32 张 / 256 MiB；超限提示，不静默丢失。截图使用当前显示器，不支持跨屏框选、长截图或云同步。当前 V2 不提供 AI 对话、Agent、笔记编辑、模型配置、账号或订阅。日程只保留 Coming Soon 和旧记录查看。

## 验收目标与实际结果

“连续操作无打断”是目标，不是全部通过的结论。功能回归通过，Collect 仍有间歇约一秒 Overlay 等待；Windows 真机、混合 DPI 与跨应用多对象粘贴未完成验收。见[当前验收](v2/PHASE2_CONTINUOUS_CAPTURE_REPORT.md)。
