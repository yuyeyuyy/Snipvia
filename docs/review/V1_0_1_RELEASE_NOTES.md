# 截然 Snipvia v1.0.1

## 快捷键更统一

新配置采用一组连续的默认键位：

| 功能 | macOS | Windows |
| --- | --- | --- |
| 快速截图并复制 | Command+1 | Ctrl+1 |
| 截图与标注 | Command+2 | Ctrl+2 |
| 收集截图 | Command+3 | Ctrl+3 |
| 隐藏／显示收纳区 | Command+4 | Ctrl+4 |
| 确认后清空收纳区 | Command+5 | Ctrl+5 |

**已有保存的快捷键继续保留，不会在升级时覆盖。** 如需使用新组合，请在「设置 → 快捷键」中调整。

## 收纳区显示更符合预期

- 快捷键、设置操作和菜单中的收纳区入口改为隐藏／显示。
- 隐藏后恢复会保留图片、顺序、尺寸和展开状态。
- 点击图堆和顶栏按钮仍可展开／收起，恢复时不主动打开设置窗口。
- 修复连续切换时旧显示回调，以及系统隐藏窗口后的恢复边界。
- 部分旧配置补齐字段时，会避开已有快捷键及其别名。

## 下载与更新

提供 macOS Apple silicon、macOS Intel 和 Windows x64 安装包。Mac 最低 macOS 14，使用 Developer ID 签名和 Apple 公证；Windows 安装包尚未签名，检查更新后手动安装。

重要截图请先导出；收纳区仍只在本次应用运行内保存。本次不更改用户数据目录或旧记录。

## 保留的已知限制

macOS ScreenCaptureKit 原生路径仍存在专项超时，保留 Electron 自动回退；本次未修改截图后端，不宣称已修复原生性能。Intel 真机、多屏／混合 DPI，以及全部第三方粘贴和拖放目标尚未全面验收。

客户端免费、无需登录，不需要模型 API Key。快速切换不会自动粘贴或发送内容。
