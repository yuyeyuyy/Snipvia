# 普通截图与标注

此功能位于当前开发代码中；已经发布的 v0.1.0 安装包不包含本次新增功能。长截图暂未实现。

## 启动

在项目目录运行 `pnpm dev`，使用固定身份的开发版。已有录屏授权继续由原有启动流程管理。

| 操作 | macOS 默认快捷键 | Windows 默认快捷键 |
| --- | --- | --- |
| 普通截图与标注 | `⌘⇧A` | `Ctrl+Shift+A` |
| AI 截图，自动理解内容 | `⌘⇧Space` | `Ctrl+Shift+Space` |
| 续拍并继续最近一次 AI 对话 | `⌘⇧Enter` | `Ctrl+Shift+Enter` |

旧版普通截图默认 `⌘⌥A` / `Ctrl+Alt+A` 会在重启后迁移为新默认值；自定义组合保持不变。如果新组合已用于其他截图操作，则保留原组合。

三个快捷键都可在「模型与设置 → 快捷键」中点击后重新录制，保存后立即生效。菜单栏 / 托盘中也可以点击「普通截图与标注」。若旧配置已将 `⌘⇧A` 用作其他操作，迁移时会为普通截图选择未占用的备选组合，以设置页面显示为准。

## 使用流程

1. 按普通截图快捷键，拖动框选区域。松开鼠标后停留在截图编辑器。
2. 拖动选区周围的八个圆点调整大小。在「选择与移动」工具下，拖动空白处移动选区，拖动已有标注移动该标注。
3. 工具栏位于选区下方；下方空间不足时放在上方。可拖动工具栏左侧的握柄调整位置。
4. 完成后选择复制、保存、定住或问 AI。

![普通截图标注工具栏，合成屏幕测试](ui/screenshot-editor.png)

| 工具 | 用法 |
| --- | --- |
| 矩形 / 椭圆 | 按住鼠标拖动绘制 |
| 箭头 | 从起点拖到箭头指向的位置 |
| 铅笔 | 按住鼠标自由绘制 |
| 文字 | 单击添加；Enter 完成；Shift+Enter 换行；双击已有文字继续修改 |
| 序号 | 连续点击添加 1、2、3 等编号 |
| 打码 | 拖出矩形区域，将该区域像素化；「粗细」调整像素块大小 |
| 删除标注 | 单击删除一条标注；也可选中后按 Delete / Backspace |
| 颜色 / 粗细 | 修改当前工具；已有标注被选中时也可修改它的样式 |
| 撤销 / 重做 | 工具栏按钮，或 `⌘/Ctrl+Z`、`⌘/Ctrl+Shift+Z`；也支持 `Ctrl+Y` |

按 V / R / E / A / P / T / N / M / D 可分别切换选择、矩形、椭圆、箭头、铅笔、文字、序号、打码、删除工具。在文字输入中这些按键正常输入文字。

## 输出和 AI 交接

- **复制并关闭**：工具栏复制按钮，或 Enter / Ctrl+C / ⌘C。将合成后的图片复制到系统剪贴板，然后关闭编辑器。编辑文字时 Ctrl+C / ⌘C 仍复制选中的文字。
- **保存图片**：打开系统保存对话框，输出 PNG。也可按 Ctrl+S / ⌘S。取消保存会返回编辑器，并保留标注。
- **定住截图**：生成可移动的置顶贴图，其他应用可以正常操作。此时不启动自动识别。贴图上的「问 AI」可随时进入智能流程；复制或右上角关闭会结束贴图。
- **问 AI**：把当前选区和标注合成后交给现有截图理解、Action 推荐和对话流程。点击「返回软件」才恢复主窗口继续同一段对话；复制、保存、关闭或取消截图后主窗口保持隐藏。手动点击 Dock 或「显示截然」仍可打开。
- **取消截图**：Esc 或工具栏关闭按钮。输入文字时 Esc 先取消当前文字编辑，再按 Esc 退出截图。

普通截图的复制、保存与贴图不请求模型，也不创建 AI 对话历史。只有选择「问 AI」后，才按当前配置进入 AI 流程。全屏原图不上传。输出图片只包含当前选区，打码合成到真实像素中，不携带可关闭的原图图层。文字工具用于添加或修改文字标注，不替换截图中的原始文字。

PNG 复制、保存与普通贴图保留选区的原生像素尺寸；选区尺寸提示使用屏幕逻辑坐标 DIP。进入 AI 后沿用原有图片压缩规则。缩放比例由实际屏幕帧计算，兼容 Retina / Windows 显示缩放。

## 验证范围

已加入合成截图的 Electron 集成测试，验证设置入口、窗口权限隔离、失效会话拦截、绘图工具、文字编辑、撤销重做、复制尺寸、打码像素变化、保存取消与输出、普通贴图、AI 交接。测试使用临时数据，不修改用户的截图历史或模型配置。Windows 实机标注交互仍需在 Windows 环境验证。
