# 设置分类菜单与统一样式

日期：2026-10-28。工作区 Snipvia-public-baseline，HEAD 2c93e3a。未提交或推送。

## 已实现

- 左侧按偏好设置、截图工作流、应用分组，提供通用、快捷键、截图、快速切换、收纳区、存储、关于七个分类；右侧只显示当前分类。
- 统一分组卡片、标题层级、行间距与 32 DIP 控件，数字输入明确显示 px / ms。沿用黑白灰语义 Token，兼容浅色、深色和系统主题。
- 快速切换拆分为显示与行为、常用目标、权限与控制；收纳区拆分为外观与尺寸、自动收起、合并输出、管理。
- 各页保持挂载，保留网页输入草稿、保存状态、更新进度和原有数据接口。保存反馈仅在对应分类出现，返回时仍可查看。
- 菜单支持 Tab、上下方向键和 Home/End。隐藏分类退出可访问树与 Tab 顺序；分类与内容分别滚动，适配最小 700×560 窗口。
- 反馈仍在标题栏；日程 Coming Soon 收入关于，旧数据查看、导出、导入及软件更新入口保留。
