# 截然 Snipvia v0.1.0

截图、理解、对话与日程处理的首个发布版本。

## 下载

| 文件 | 适用系统 |
| --- | --- |
| `Snipvia-0.1.0-arm64.dmg` | macOS 14+，Apple 芯片（M 系列）；暂不支持 Intel Mac |
| `Snipvia-Setup-0.1.0-x64.exe` | Windows 11 x64 |
| `INSTALL-macOS-zh-CN.md` / `INSTALL-Windows-zh-CN.md` | 对应平台安装与使用说明 |
| `SHA256SUMS.txt` | 安装包和说明文件的 SHA-256 校验值 |

## 主要功能

- 快捷键框选与置顶截图；浮动胶囊操作区、可调整大小的截图旁对话窗。
- 自动理解截图内容并执行预测分支；支持流式回答、停止生成和手动追问。
- 续拍快捷键将新截图接入上一次对话上下文，跳过新截图意图分析。
- 置顶截图获得焦点后按 `Ctrl+C` 复制图片并关闭。
- 截图日程草稿、月历与本地历史；Mac 可在核对并确认后添加到系统日历或提醒事项。
- 自定义模型服务支持 HTTP / HTTPS；API Key 使用 macOS 钥匙串或 Windows DPAPI 保护。
- 所有现有预测分支均可编辑名称、适用内容和指令，也可以关闭或新增自定义分支。
- 开机自启设置；Windows 登录后在托盘运行。
- Windows 屏幕源匹配与缩放适配，修正移动截图时对话窗累积变大的问题。

## 首次使用

1. 安装并打开截然，在“模型与设置”配置自己的视觉模型与 API Key。
2. Mac 按提示授权录屏。新截图快捷键：Mac `⌘⇧Space`，Windows `Ctrl+Shift+Space`。
3. 续拍追问：Mac `⌘⇧Return`，Windows `Ctrl+Shift+Enter`。两个快捷键均可在设置中录制修改。

更新前退出旧版；Mac 替换“应用程序”中同一份应用，Windows 安装到原目录。免安装版本移动位置后，请重新开启自启。

## 已知边界

- Mac 仅支持 Apple 芯片，使用临时签名且未 Apple 公证；Windows 安装包尚未代码签名。
- Windows 安装器、系统登录自启及完整跨屏兼容性仍需真机验收；Windows 暂不写入系统日历或待办。
- 历史和日程保存在本机文件中。暂不提供应用内定时提醒、ICS、双向日历同步或自动更新。
- 完成框选后，所选截图可能自动发送至已配置的模型服务。全屏框选帧不会上传；日程写入系统应用需要用户确认。软件不附带 API Key 或模型额度。

类型检查、Lint、108 项单元测试、生产构建与使用临时数据及模拟图片的 Electron 冒烟测试通过。Windows 安装器与登录自启的真机验证不包含在这些结果中。
