# 截然 Snipvia v0.2.3

## AI 对话工作区

- 正式开放主窗口 AI 对话，支持新建、恢复、继续对话，以及流式回答、停止生成和重新生成。
- 全新黑白灰聊天界面：居中欢迎页、自动增高输入框、紧凑模型选择和附件菜单；开始对话后输入框固定在底部。
- 侧栏按日期分组显示会话，支持重命名、删除确认与长标题截断；切换会话时恢复已有内容与模型选择。
- 用户消息靠右显示，AI 回答采用自然排版，支持 Markdown、代码、表格和消息复制。
- 优化长对话滚动：主动向上查看内容时不会被流式输出拉回底部，可点击返回最新消息。

## 笔记与预测分支

- 对话可携带明确选择的 AI 笔记或截图预测分支上下文。
- AI 提出笔记和分支修改后，先展示差异预览，由用户确认后保存，也可取消。
- 保存前检查上下文是否失效和结构是否合法；主窗口 AI 对话不会直接覆盖笔记或执行任意命令。

## 图片输入

- 支持本地 PNG / JPEG、剪贴板粘贴、拖入图片，以及选择已有 Snipvia 截图。
- 发送前可预览和移除附件，历史消息可以查看已发送图片。
- 沿用现有模型与密钥配置；已明确不支持图片输入的模型会给出提示。

## 修复与兼容性

- 修复同一服务接口下不同模型的选择混淆，以及历史会话模型配置失效时的提示。
- 修复来源截图预览隐藏、选择器箭头偏移，并优化窄窗口、亮暗主题和中文输入法交互。
- macOS 14+；提供 Apple 芯片（arm64）与 Intel（x64）的独立安装包。
- 已安装 v0.2.2 的用户可在「设置 → 关于」检查、下载，然后选择「重启并更新」。更早版本请先手动安装新版。
- 本次只更新 Mac；Windows 预览版仍为 v0.2.1。Intel 真机、多显示器、混合 DPI 的完整人工验收尚未补齐，模型服务可用性取决于用户配置与权限。
