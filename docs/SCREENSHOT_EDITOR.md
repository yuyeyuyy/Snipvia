# 当前截图编辑器

Edit 使用设置中的“截图与标注”快捷键（例如用户自配 Command+2；默认值及已有配置不变），沿用 src/renderer/src/capture/editor/。框选后标注、撤销/重做、原像素 PNG、复制并关闭、原生保存及 Pin 保留。取消保存不丢失编辑；Esc 取消本次截图，文字输入时 Esc 先放弃当前文字草稿。

裁剪可拖动四条边和八个圆点，圆点视觉保持小型、命中区为 22 DIP。选择与移动工具选中矩形、椭圆或打码框后，拖动方形控制点调整标注尺寸；调整可撤销，最小 3 DIP，限制在当前裁剪区域内。文字工具点击已有文字直接编辑，选择工具双击文字编辑；Enter 提交、Shift+Enter 换行。未改变的文字和无位移点击不增加撤销步骤。

每张钉图独立保存到关闭；后续截图只暂时隐藏、完成后无焦点恢复。图片支持原生边缘缩放、拖动位置，悬停显示复制并关闭和关闭按钮，也可 Esc / ⌘或Ctrl+C。双击图片移除当前钉图，不删除已保存原图或其他钉图；单击及拖动不触发删除。主钉图窗口预热复用，额外窗口按需创建、关闭销毁，最多 32 张；截图字节仍受 Store 的原有内存限制。不自动保存为历史，不上传图片。

场景模型与绘制分别位于 model.ts / draw.ts，坐标由 shared/geometry.ts 在 DIP 与真实像素间换算。Main 验证会话、PNG 头、尺寸和解码结果后输出；Pin IPC 仅访问发送窗口自身会话。Quick 不进入编辑器；Shelf 居中预览复用 Shelf 窗口，“定住”才另开钉图，不预先开发新的编辑引擎。

自动化范围及真机边界见[本轮修复记录](v2/EDITOR_PIN_FIX.md)。Windows、原生缩放手感及实际混合 DPI 仍需真机验收。
