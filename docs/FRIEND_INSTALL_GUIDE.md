# 截然（Snipvia）v0.2.1：Mac 安装与使用

适用：macOS 14+、Apple 芯片（M 系列）。Intel Mac 暂不支持。使用安装包无需 Node.js、pnpm 或下载源码。

## 安装与升级

1. 从 [v0.2.1 Release](https://github.com/yuyeyuyy/Snipvia/releases/tag/v0.2.1) 下载 `Snipvia-0.2.1-arm64.dmg`，可用 `shasum -a 256` 与 `SHA256SUMS.txt` 核对。
2. 升级前从菜单栏选择“退出截然”。打开 DMG，将 **Snipvia.app（截然）** 拖入“应用程序”，替换旧版。本机设置、历史和笔记目录保留；仍建议先备份重要笔记。
3. 以后从同一个“应用程序”路径打开，避免系统识别为多份应用。

本版使用临时签名，尚未 Apple Developer ID 签名或公证。首次打开如被拦截，尝试打开一次后，在 **系统设置 → 隐私与安全性** 按本次拦截提示选择“仍要打开”。若提示损坏或管理员策略禁止运行，请反馈问题，不要关闭系统安全保护。

## 录屏权限与账号

首次截图需要 **录屏与系统录音** 权限。按提示进入系统设置，为“应用程序”里的 Snipvia.app 授权，然后退出并重新打开。开发版“截然 Dev.app”拥有独立身份，开发版权限不会自动授予安装版。

标题栏的 **登录** 使用邮箱验证码登录或注册；默认账号服务为 `https://console.umbraticus.cn`。管理员发放的有效体验、订阅或永久资格可以使用截图对话。无资格仍可普通截图；启动 AI 截图会进入普通截图并提示联系管理员。

## 截图与对话

| 操作 | 默认入口与行为 |
| --- | --- |
| 普通截图 | **⌘⇧A**，或菜单栏“普通截图与标注”；支持标注、复制、保存和定住。 |
| AI 截图 | **⌘⇧Space**，或菜单栏“AI 截图”；会员截图后显示置顶图片与对话窗，等待输入。 |
| 预测分支 | 在对话窗空输入按 **Enter**，执行预测；输入问题再按 Enter 则直接对话。 |
| 续拍追问 | **⌘⇧Enter**，沿用最近对话上下文，跳过预测。 |
| 复制与关闭 | 普通截图点“复制并关闭”；置顶图片获得焦点后按 **⌃C**；也可点 × 或按 Esc 取消框选。 |
| 返回主窗口 | 点击“返回软件”，或手动点击 Dock / 菜单栏“显示截然”。复制、保存、关闭或取消截图不会自动打开主窗口。 |

快捷键可在标题栏的 **设置图标 → 快捷键** 修改。截图对话的独立主导航暂时隐藏，已有会话可以从“历史对话”打开。

## 模型、预测与隐私

在 **设置图标 → 配置厂商** 选择支持图片和工具调用的对话模型，填写自己的 API Key，保存并使用。支持 OpenAI、千问、Gemini、DeepSeek、Kimi、智谱、豆包、硅基流动、OpenRouter 和兼容接口；模型能力及接口来源需与 Key 匹配。

客户端对话模型与服务端预测是两套配置：管理员在网页控制台配置视觉模型和 TypeSafe Jev；客户端空输入预测会使用已启用的服务端链路。四个内置分支及自定义分支的名称、适用内容、执行指令与绑定笔记本均可编辑。

软件不附带私人 Key 或模型费用额度。Key 在本机加密，Mac 加密密钥由钥匙串保护；升级后可能再次询问钥匙串访问。截图、历史和 Markdown 笔记保存在本机，只有选中区域在请求预测或发送问题时上传到相应服务。服务端预测只累计次数，不留存截图或提示词。

## AI 笔记与日程

主窗口默认进入 **AI 笔记**。创建笔记本或链接已有 Markdown 目录；文件列表在左，大纲在右，两侧和主菜单都可连续收起。支持代码高亮、点击代码语言复制、表格、拖拽文件和文件夹、附件及 ZIP 导出；`assets/` 在文件树中隐藏。移除笔记本只取消链接，不删除原文件。

为对话或预测分支绑定笔记本后，Agent 可以检索并自动整理 Markdown，实际写入后才回复，下方显示可点击的文件变更。输入“不要写入笔记”可只回答。Mac 可在当前笔记本的沙箱中执行命令与脚本；脚本和无法静态确认的命令需要单次批准，默认不联网、不读取应用密钥，单次执行最多 10 秒。执行时间线可展开查看。笔记修改卡片提供整轮撤销，之后被修改过的内容不会覆盖。

日程先生成草稿；核对日期、时间、时区并确认后才保存。写入 Mac 日历或提醒事项还需选择目标并确认，系统可能询问自动化权限；不会自动同步日历。

## 问题排查

- 截图无反应：检查录屏权限，重新打开同一份应用；快捷键占用时使用菜单栏入口。
- 没有 AI 对话窗：确认已登录并有有效资格，无资格截图会显示联系管理员。
- 预测失败：把客户端显示的阶段与脱敏错误交给管理员；空输入 Enter 可重试。
- 对话失败：检查客户端模型、Key、图片 / 工具调用能力、接口来源与服务余额。
- 完全退出：菜单栏“退出截然”或 **⌘Q**；关闭主窗口只隐藏窗口。
