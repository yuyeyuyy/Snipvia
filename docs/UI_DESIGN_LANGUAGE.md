# Snipvia（截然）界面设计语言

本文固定 Snipvia 的两套界面语言。新增页面和调整现有页面时，先按页面职责选择其中一套，不在同一页面混用两套布局骨架。

官网和管理后台已迁入独立私有仓库；本规范仅约束桌面客户端的两套页面语言，不引用已迁出的官网规范。

## V2 Phase 2 截图收纳

Shelf 是工作区语言的小型浮窗，复用 WorkspaceHeader、Button 与现有黑白灰 Token，不增加主页面壳。收起时 184×58 DIP，展开时至多 420×540 DIP，靠截图显示器工作区右上角；主动展开才聚焦，新增图片 showInactive。缩略图保留原色；删除、排序与清空均作用于稳定 ID。清空使用原生确认框。展开态支持逐项选择、预览、删除、拖拽/方向键按钮排序；底部提供最大宽度、间距、合并复制与 PNG 导出。收纳只在本次应用运行内保留，容量上限明确报错。隐藏后小型数量反馈自动结束，减少动态效果时不飞入。实际截图、性能保留项与验证见 [Phase 2 报告](v2/PHASE2_CONTINUOUS_CAPTURE_REPORT.md)。Phase 1 中“不增加收纳窗口”的说明仅代表当时范围。

## V2 Phase 1 当前界面（2026-10-23）

以下历史工作台规范保留其原有验收范围。V2 开发分支当前以设置语言为唯一主窗口：通用、快捷键、截图、存储、关于；日程只以 Coming Soon 条目和旧记录只读入口存在。删除 AI 对话、笔记、历史工作台与快捷导航，不新增第三套页面骨架。

沿用原 AppShell 的 48px 原生标题栏、公共 Button/Dialog、黑白灰 Token、主题广播与分组行语言。去掉业务侧栏。24px 页面标题、15px 分组标题、13px 行标签和 12px 描述区分层级；正文在右侧控件旁保持清晰换行。顶部分类定位到实际设置区域，不创建虚假配置开关。宽窗口最大内容宽度 900px，窄窗口收紧间距；更新说明保留安全 Markdown、拒绝外链图片与不安全 URL。

主窗口只初始化设置与权限状态，点击「查看旧记录」才读取旧索引；旧记录 Dialog 只读展示及导出，原 Markdown 从原文件夹备份。反馈保留 QQ 群号与复制，通用剪贴板 IPC 已从 notes 命名空间提取。截图 Overlay/贴图使用原来的透明窗口和握手；标注工具栏移除「问 AI」。不增加收纳窗口、动画或未来功能入口。

## 共同原则

- UI 2.0 支持 Light / Dark / System，默认跟随系统。客户端统一采用 Monochrome Minimalism：浅色为中性白灰，深色为独立优化的中性深灰；主要动作、选中和焦点均使用黑白灰。颜色统一引用 [语义 Token](../src/shared/design-tokens.json)，组件不写颜色常量。
- 使用 macOS 原生工具的克制感：细边框、少量阴影、中性状态色及明确图标和文字；深色层次通过不同表面区分，避免反转浅色颜色。
- 使用系统字体栈，以 SF Pro 显示为优先；标题明确，辅助说明降低对比度。
- 导航使用 `bg-nav`，窗口使用 `bg-window`，分组表面使用 `bg-panel`，弹出层使用 `bg-raised`。保持清楚的导航和稳定的内容宽度。
- 左侧导航只在「截图日程」有未查看识别记录时显示数字；进入日程页后清零。历史对话等其他入口不显示记录总数。
- 控件只在当前任务需要时出现；不使用彩色数据块、厚重阴影或 SaaS 仪表盘式卡片堆叠。
- 文字使用 `text-primary / secondary / muted / disabled`，边线使用 `border-subtle / default / strong`；代码块使用独立的 `code-*` 灰度语法层级，关键字加重，注释标灰并使用斜体。
- 选中使用 `bg-selected / text-selected`；主要动作使用 `accent / text-on-accent`，聚焦使用 `focus` 的清晰实线描边，不使用蓝色光晕。截图像素与标注色不随主题变化；跨截图背景的遮罩和尺寸标记使用固定对比度的 `capture-*` Token。
- 品牌图标以 `UI/` 中的设计为源：macOS 使用 `Snipvia-2-mac.icon` 分层图标，标题栏使用与托盘轮廓一致的 `currentColor` 黑白矢量图标；彩色应用素材仍保留原件，Windows 使用 `Snipvia-Win.png`，应用与托盘使用 `Snipvia-Win.ico`。中文名为「截然」，打包文件及权限身份继续使用稳定的 `Snipvia.app` 与 `com.snipvia.desktop`。更新 Mac 源图标后运行 `pnpm icons:build`；开发启动器同步 ICNS 和分层资源、更新图标声明并重新登记固定开发应用，系统权限图标的验证与刷新见 [开发说明](DEVELOPMENT.md#开发应用的系统图标)。
- 弹窗使用 `bg-overlay` 遮罩和紧凑标题栏；公共原生 Dialog 使用 `radius-dialog`、`shadow-popover`。已有业务弹窗本轮接入主题，内部布局后续按页面逐步调整。

## 主窗口标题栏与导航

![浅色主窗口](ui/ui2-monochrome/settings-light.png)

![深色主窗口](ui/ui2-monochrome/settings-dark.png)

- 主窗口使用 48px 高的统一标题栏，保留系统原生窗口控制。macOS 为红绿灯按钮预留左侧空间，Windows / Linux 通过窗口控制覆盖区域预留安全空间。标题栏空白处可拖动窗口，按钮区域正常响应点击。
- 「截然」图标和名称位于标题栏左侧，旁边放菜单栏收起 / 展开按钮。快捷导航（⌘K / Ctrl+K）和设置位于右侧；客户端没有登录或账号入口，设置显示对称的齿轮图标。图标按钮均有可访问名称、悬停提示和选中状态。
- 左侧提供 AI 对话、AI 笔记、截图日程、历史对话四个入口；主窗口默认进入 AI 笔记，AI 对话也可通过快捷导航进入，不显示截取区域按钮、工作空间字样、账号邮箱或本机存储说明。截图入口继续位于任务页、系统菜单、托盘和快捷键中。
- 展开时导航宽度为 176px，AI 对话页为 232px；不超过 1050px 的窗口默认收起，允许手动展开；收起后为 52px，只显示菜单图标，隐藏文字和数字。宽度与图标位置连续过渡，文字淡出；展开、收起过程中可反向切换。通过悬停提示查看名称及未查看日程数量，收起状态在下次启动时恢复，切换时保留当前页面和编辑内容。系统开启「减少动态效果」时直接切换。
- 历史图标使用完整圆环与时钟指针，不附带回转箭头；设置图标的齿轮外轮廓和中心圆保持对称。
- 标题栏与左侧导航属于共同应用框架，内容页继续使用工作区或设置两套既有设计语言。
- 基础样式先加载，共享精修样式随后加载，避免开发模式中的异步加载顺序覆盖窗口网格。标题栏必须横跨窗口，侧栏从标题栏下方贴左排列，主内容与侧栏相邻；展开、收起和紧凑窗口均校验边界，不预留额外空列。
- 2026-10-09 布局修复已通过构建版窗口边界与收起动画检查，以及开发版延迟基础样式 500ms 的实际加载验证。设置页范例见[修复后布局](ui/settings-layout.png)。
- 2026-10-07 已接入 UI 目录中的新版平台图标。Mac 标题栏与固定开发应用的图标同步、签名检查及桌面回归通过；Mac 应用目录包含新 `Assets.car` 和 ICNS，Windows 交叉构建的 EXE 包含新 ICO 全部 7 种尺寸。Windows 界面仍待真机确认。

## UI 2.0 主题与公共组件

- 主进程统一保存外观模式并通过 Electron `nativeTheme` 解析实际主题；运行时系统变化自动同步到已创建窗口，新窗口通过 Preload 的只读内存快照初始化。
- 在「设置 → 外观 → 主题」实时切换。偏好独立于模型配置，模型切换不重置主题。旧设置默认 System，密钥仍保留原有加密存储。
- 主窗口只有一个 `AppShell`。笔记保持现有挂载与保存行为；已访问的其余页面通过 React `Activity` 保留状态，隐藏时暂停页面 Effects，不创建额外布局盒。
- 新公共 Button / IconButton / Input / Select / Dialog / LoadingState 使用 Token；原有 Popover、Tabs、Switch、空状态和滚动区域复用现有结构并接入语义颜色。Tooltip 保留原生 `title`，不添加 UI 依赖。
- Token 修改后运行 `node scripts/generate-design-tokens.mjs`。CSS 在 HTML 中先于 React 加载，浅色 / 深色均有启动前样式，透明截图与浮窗根节点保留透明。
- 主题持久化与同步机制见 [阶段 2 实施记录](UI_2_0_STAGE_2.md)；当前黑白灰 Token、状态与验证见 [阶段 2.5 Monochrome 修正](UI_2_0_MONOCHROME.md)。
- 普通说明文字在浅灰选中背景上也保持至少 4.5:1 对比度，浅色次要文字采用 `#686868`。成功、警告、错误不依赖颜色：保留操作结果文字，并显示勾选、感叹号或叉号。禁用控件使用降低对比度和不可操作状态。

## 工作区页面设计语言

![工作区页面范例](ui/workspace-page.png)

工作区页面强调当前任务和主要内容。日程、对话、历史必须共享同一页头和内容容器规则。

### 布局

- 页面使用 `workspace-panel`：公共留白为纵向 16px、横向 24px，紧凑窗口为 12px / 16px。业务页面各自适配内容宽度；笔记采用阶段 4 的沉浸式编辑布局。
- 页头复用 `WorkspaceHeader`，至少 44px 高，标题为 14px / 600 字重。右侧放快捷键、记录入口或当前任务操作，不增加重复标题栏。
- 页面不叠加第二层全局工具栏，也不重复显示同一个标题。
- 主内容位于页头下方 18px。笔记、日历与历史优先采用连续表面、留白和细分隔线；只有确有边界的任务容器使用 `workspace-card`。

### 表面与控件

- 主内容卡片使用 1px 中性边框、11px 圆角和极轻阴影。
- 页头按钮高度 32px、8px 圆角，使用白色或浅灰背景；图标与文字保持紧凑间距。
- 快捷键显示为小型 `kbd` 标签，放在操作区，不占用主内容。
- 日历使用紧凑连续网格和日期详情；历史使用无外框的紧凑列表与同屏预览；截图对话保留现有内容容器，逐阶段改造。
- 空状态仍放在主要内容卡片内，使用单一图标、标题、说明与必要操作。

### 交互

- 主操作靠近它影响的内容。页面级操作放页头，内容级操作放卡片内部。
- 历史删除、清空等破坏性操作使用明确的文字和中性高对比描边，仅在可执行时出现。
- 记录详情、识别历史和编辑器使用统一弹窗，不在页面上并排堆叠额外面板。

### 截图日程与历史对话（阶段 3）

- 日程采用月历主区域与 272–360px 日期详情，窄内容区域缩到 250px；不足 600px 时上下排列，独立内容滚动。日期格为 64–84px，不塞长事件标题，不使用大面积选中色块。
- 今天是高对比实心日期，选中日期有灰底小标签及边线；实心点表示日程，空心点表示来源截图，菱形表示截止事项。点击日期或用方向键更新真实日期详情，Home / End 选择本周边界，PageUp / PageDown 切月；月份长度变化正确限制日期。
- 日期详情按全天、时间安排、截止事项分组，并列出当天创建的来源截图。跨日与时区继续使用既有 Temporal 日期规则；午夜结束的时间段不额外占下一天。缺少日期的结果不会被放入今天，识别失败记录仅出现在实际截图日期的来源区与识别记录中。
- 识别记录与事件编辑复用公共 Dialog；保存到截然、Mac 日历与提醒事项仍为原有明确操作。本阶段保持现有业务，并未引入自动保存或新的待核对队列。
- 历史为 240–300px 紧凑列表与弹性详情。每行约 56px，日期分组标题可吸顶；灰底、字重和短竖线表示当前对话，删除按钮悬停或键盘聚焦时显示。
- 搜索标题、模型与厂商，不为搜索批量读取消息或图片。厂商筛选与清除搜索复用公共控件；空结果、空记录、读取中和读取失败分别表达。
- 预览使用只读 `history:read`：不改变活动截图、不取消 Agent、不发送模型请求或更新记录。只有「继续对话」调用既有恢复入口；来源图片按需展开，消息复用现有 Markdown 与网页来源展示。
- 删除与清空使用公共原生 Dialog，默认聚焦取消，确认前不写存储。清空明确作用于全部记录而非筛选结果。列表与预览独立滚动，每条预览的滚动位置在页面及主题切换时保留。
- 小窗口减少详情留白；内容宽度不足 580px 时切为列表 / 详情两态并提供返回按钮。两页共享 WorkspaceHeader、Monochrome Token 与原有主窗口骨架。

### AI 笔记工作区

![AI 笔记工作区 · Light](ui/ui2-stage4/notes-light-1120.png)

![AI 笔记工作区 · Dark](ui/ui2-stage4/notes-dark-1120.png)

AI 笔记复用 `workspace-panel` 与 `WorkspaceHeader`，移除内层卡片外框和阴影，使用连续编辑表面，不新增第三套页面壳。

- 页头左侧是可切换的笔记本名称，使用居中的上下双箭头；右侧依次放文件列表、大纲显示按钮和打包导出。首次进入时，内容中央显示创建笔记和打开已有笔记本。
- 默认采用左侧文件树与中央编辑器；大纲默认收起，按需打开，反向链接位于大纲下方。宽内容区域的文件树 / 大纲均为 200px；内容不足 900px 时文件树为 184px，大纲改为 212px 辅助浮层；不足 620px 时文件树也以辅助浮层展开，保留关闭入口，避免三栏同时挤压正文。
- 文件列表与大纲可独立收起，宽度连续缩小、内容淡出；恢复入口始终保留在页头。两侧全部收起后正文使用完整工作区宽度，编辑器、目录展开状态和输入内容保持。隐藏栏退出键盘导航；系统开启「减少动态效果」时关闭动画。
- 页头与编辑工作区使用全部可用宽度，正文最大 760px（含横向留白），居中排版；编辑器 15px 系统字体与 1.85 行高。宽屏不会把每行文字无限拉长；实时预览和源码模式仍使用原 CodeMirror 实例、Undo 历史和高度测量逻辑。
- 文件栏标题旁放新建笔记 / 文件夹，下面一行放刷新、排序、自动定位与折叠图标。行末更多操作按需显示，不为每个文件堆叠按钮。
- 文件夹和大纲使用 SVG 箭头，以图标中心旋转。大纲用标题缩进、细纵线和折叠箭头表达层级。点击跳转；反向链接在大纲下方，使用轻量文本行。
- 文件树隐藏根目录的 `assets` 和其中条目，附件仍可在正文中使用。拖动文件或文件夹时，源行使用黑白高对比，目标文件夹及已展开子树使用灰色背景；光标旁显示深色紧凑浮层，包含文件 / 文件夹图标、名称和「移动到…」。源行、目标和浮层均复用 Monochrome Token，保留用户附件原色。
- 文件夹行和其子项区域接收拖入；列表空白处及「笔记本根目录」行接收移回根目录。悬停 650ms 展开折叠目录，靠近列表上下边缘连续滚动。松开后等待保存并执行移动，跟随打开文件的新路径、保留文件夹展开状态，更新可确定的笔记链接。禁止移入自身 / 子目录、同名覆盖和无效目标，浮层显示原因；Esc、取消或离开窗口结束提示与滚动。
