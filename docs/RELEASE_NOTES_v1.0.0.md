# 截然 Snipvia 1.0.0

截然转向轻量、免费、本地优先的截图与收纳工具，无需账号、模型或 API Key。

- 快速截图后直接复制；截图编辑支持标注、文字再次编辑、裁剪和原图输出。
- 支持多张独立钉图、调整尺寸、复制并关闭，以及双击移除当前钉图。
- 透明收纳图堆可展开成右侧单列，支持滚动、居中放大预览、排序、多选和贴边自动收起；图片有细边区分背景。
- 支持单图复制、合并复制、全部独立原图复制、PNG 导出及原生文件拖出。复制后可显示快速切换条。
- 可配置常用应用和网页；macOS 支持 Chrome 已有 ChatGPT / DeepSeek 标签匹配、网站图标与浏览器角标，以及可选的输入框聚焦。不会自动粘贴或发送内容。
- 设置采用左侧分类菜单和统一分组卡片，支持浅色、深色及系统主题，保留快捷键与既有数据兼容。

## 升级前说明

收纳区仅在本次应用运行内保留，重要截图请先导出；最多 32 张 / 256 MiB。全部复制保留独立文件，是否支持多文件粘贴取决于目标应用。

此版本聚焦截图与收纳，不再提供旧版 AI 对话、Agent、笔记编辑、模型调用或账号功能。旧历史、日程与笔记文件保留，可从设置中只读查看、导出或导入旧截图，不会自动删除原数据。

快速切换、浏览器控制和输入框聚焦受系统权限与目标应用支持限制。Windows 当前保留检查更新与手动安装入口，尚未配置签名自动安装更新。

## 安装包与验证

- macOS Apple Silicon / Intel：提供 DMG 与 ZIP，均已使用 Developer ID 签名、通过 Apple 公证与 Gatekeeper 检查，保留独立 GitHub 更新渠道。
- Windows x64：提供未签名 NSIS 安装包，已在 Windows runner 完成实际安装、合成截图/复制/收纳测试及卸载；保留检查更新与手动安装。尚无 Windows 代码签名证书，系统可能提示未知发布者。
