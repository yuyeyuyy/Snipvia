# 截然（Snipvia）v0.2.1：Windows 安装与使用

适用：Windows 11 x64。使用安装器无需 Node.js、pnpm 或其他开发环境。本版提供 EXE 安装器，验证范围见 [发布说明](RELEASE_NOTES_0.2.1.md)。

## 安装与升级

1. 从 [v0.2.1 Release](https://github.com/yuyeyuyy/Snipvia/releases/tag/v0.2.1) 下载 `Snipvia-Setup-0.2.1-x64.exe`。PowerShell 可用 `Get-FileHash -Algorithm SHA256 .\Snipvia-Setup-0.2.1-x64.exe` 与 `SHA256SUMS.txt` 核对。
2. 如旧版正在运行，先从系统托盘退出截然，再双击安装器，选择目录并完成安装。
3. 从开始菜单打开。升级时使用原安装目录；设置和历史保存在当前 Windows 用户的数据目录中，笔记保存在自己选择的文件夹。建议先备份重要笔记。

安装包尚未代码签名，系统可能显示 SmartScreen 或未知发布者提示。确认来源与校验值；受管理电脑请遵循管理员策略，不要关闭系统安全保护。

## 账号与模型

标题栏 **登录** 使用邮箱验证码登录或注册，默认账号服务为 `https://console.umbraticus.cn`。管理员发放的有效体验、订阅或永久资格可以使用截图对话；无资格仍能普通截图，启动 AI 截图会进入普通截图并提示联系管理员。

在标题栏 **设置图标 → 配置厂商** 选择支持图片和工具调用的对话模型，配置自己的 API Key。支持 OpenAI、千问、Gemini、DeepSeek、Kimi、智谱、豆包、硅基流动、OpenRouter 和兼容接口；软件不附带分享者的 Key 或额度。Windows 使用当前用户的 DPAPI 加密凭据。

服务端预测由管理员单独配置视觉模型与 TypeSafe Jev；客户端对话模型与它相互独立。只有选中区域在预测或发送问题时上传，截图与对话保存在本机；服务端预测只累计次数，不留存截图或提示词。

## 截图与对话

| 操作 | 默认入口与行为 |
| --- | --- |
| 普通截图 | **Ctrl+Shift+A**，或托盘菜单“普通截图与标注”；支持标注、复制、保存和定住。 |
| AI 截图 | **Ctrl+Shift+Space**，或托盘菜单“AI 截图”；会员截图后显示图片与对话窗。 |
| 预测分支 | 对话窗空输入按 **Enter** 才预测；输入问题按 Enter 则直接对话。 |
| 续拍追问 | **Ctrl+Shift+Enter**，沿用最近一次会话。 |
| 复制与关闭 | 普通截图点“复制并关闭”；置顶图片获得焦点时按 **Ctrl+C**；点击 × 关闭，框选时 Esc 取消。 |
| 返回主窗口 | 对话窗“返回软件”或点击托盘；复制、保存、关闭和取消截图不会自动打开窗口。 |

快捷键可在 **设置图标 → 快捷键** 修改。独立“截图对话”导航暂时隐藏，历史会话仍可以打开。

## 笔记与其他设置

- **AI 笔记**：链接 / 创建本地 Markdown 笔记本，支持自动保存、代码高亮与复制、表格、文件拖拽、附件与 ZIP 导出。移除笔记本只取消链接，保留原文件。
- **自动整理笔记**：对话绑定笔记本后 Agent 可检索、创建和编辑 Markdown，完成后回复并显示可点击的文件列表；可确认撤销整轮修改，后续改动不会覆盖。Windows 暂不开放 Agent 命令 / 脚本沙箱。
- **截图预测**：四个内置分支与自定义分支都能编辑名称、适用内容、指令和笔记本绑定。
- **开机自启**：设置“常规”中开启，登录 Windows 后在托盘运行。开关读取系统实际状态；在任务管理器禁用后回到设置可看到变化。移动应用路径后需要重新开启。
- **日程**：核对草稿后保存到截然；Windows 暂不写入系统日历或待办。

## 问题排查与边界

- 快捷键占用时改用托盘菜单，或录制新的组合。
- 截图为空时，确认没有截取受保护画面或安全桌面；检查日志中的错误。
- 对话窗没有出现时，检查登录和有效资格；预测错误请联系管理员，对话错误请检查客户端模型配置。
- 本版默认 Electron 截图后端，macOS 的 ScreenCaptureKit 不用于 Windows。混合 DPI、多屏、受保护内容、不同显卡和安全软件仍需自己的设备验证。
- 完全退出请用托盘菜单“退出”；关闭主窗口会保留后台进程。
