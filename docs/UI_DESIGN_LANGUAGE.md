# V2 界面设计语言

## 两套现有语言

设置中心、权限和偏好使用分组行：左侧标签/说明，右侧控件。Shelf、框选、编辑和预览为工作区表面；Shelf 复用 WorkspaceHeader。不要新增第三套主页面壳。

保持 Light / Dark / System、系统字体、黑白灰语义 Token 和键盘焦点。页面标题 24px、分组标题约 15–16px、标签 13px、描述 12px；截图及标注保持原色，不通过灰度滤镜改变图片。Token 来源是 src/shared/design-tokens.json，由 scripts/generate-design-tokens.mjs 生成 CSS。

## 设置与收纳

设置采用固定左侧分类菜单和右侧独立内容页，不再用顶部锚点滚动整页。菜单按“偏好设置 / 截图工作流 / 应用”分组，提供通用、快捷键、截图、快速切换、收纳区、存储、关于七个入口。当前分类有浅色卡片式选中态，支持点击、Tab、上下方向键、Home/End；内容单独滚动，其他分类不进入可访问树和 Tab 顺序。切换分类保持组件挂载，保留输入草稿、异步保存与更新状态；保存反馈只在对应分类展示，返回时仍可查看。通用包含外观，日程 Coming Soon 保留在关于。

标题栏保留设置标题和反馈；内容页为 24px 分类标题、12px 描述，分组标题 12px，卡片标签 13px、说明 12px。统一圆角分组卡片、68 DIP 左右的行高、32 DIP 控件与数字单位；沿用语义 Token，兼容浅色、深色及系统主题。快速切换分为显示与行为、常用目标、权限与控制；收纳区分为外观与尺寸、自动收起、合并输出、管理。700×560 最小窗口下，长操作组换行，分类菜单与内容分别滚动，保持所有入口可达。反馈 Dialog 展示 QQ 群号 643251313，并提供复制、成功/失败提示及焦点恢复。

Shelf 使用透明图堆，不绘制面板背景、外框或页面底板；照片保持原始比例和原色，以约 1 DIP 的主题细线区分图片边缘和背景；缩放后线宽保持一致，边框贴合实际图像，不包围长窄图的留白。收起时最近 5 张以小角度叠放，充分使用宽度，允许在预览中放大小尺寸截图。展开后是右侧单列，按各图比例紧凑排列，常规图片间距 12 DIP。点击收起的图堆只向下展开列表；默认列表窗口占当前屏幕工作区高度的 3/4，图片少也不缩短，超出视口后滚动。宽度只在设置中调整，顶栏不再显示加宽按钮。

收起时，鼠标悬停或键盘聚焦照片，在照片底部显示同排三个 28 DIP 半透明图标：全部复制、合并复制、导出 PNG。展开后，这三个输出按钮固定移到顶栏，与多选、收起和隐藏并排；照片上仅保留悬停/聚焦时出现的左上复制、右上删除。全部复制提交全部独立原图；多选只影响合并和导出，选择按钮仅在进入多选后出现。普通拖动将原图作为文件拖出，供支持文件拖放的文件夹、聊天/附件输入区域接收；按住 Alt 拖动排序，Alt+方向键仍可排序；不显示底部尺寸拖柄、三点菜单或尺寸浮层。

展开后再点击单张照片，以 340ms 的 transform 动画放大到所在屏幕工作区中央；使用现有 Shelf 原生窗口承载原图预览，不创建额外窗口。点击图片、空白或 Esc 以 240ms 动画返回；保留复制、定住、删除和关闭。顶栏复用 WorkspaceHeader，以小型悬浮控件显示展开和隐藏，语义标题仍可被辅助技术读取。

复制或导出真正成功后，对应按钮显示对号，1000ms 后恢复，不显示成功文字条。取消不显示对号，失败仍明确提示。按钮保留 title、aria-label 和键盘焦点。照片阴影反向补偿卡片缩放；旋转轮廓、滚动和窗口边缘预留 16 DIP 渐隐空间，仅改变透明度，不加底板或图片滤镜。

默认鼠标离开 1800ms 后向右贴边收起，只留下 22×84 DIP 透明窗口中的拉出手柄；鼠标悬停手柄即平滑恢复，也保留点击和键盘入口。手柄始终以折叠图堆的位置为锚点，展开列表及自定义展开高度不会把手柄推向屏幕中央。拉出手柄不依赖窗口聚焦，不会因此打开设置窗口。拖拽、合并/导出和居中预览期间保持面板。设置中心新增“收纳区”，沿用左侧标签/说明、右侧控件的分组行，管理宽度 280–960 DIP、展开高度模式（屏幕 3/4 或自定义 300–1600 DIP）、自动收起与等待时间、合并参数和确认清空。超出工作区的尺寸自动限制，不显示额外页面壳。

新增截图以 showInactive 显示反馈。飞入使用 340ms 的连续采样弧线、等比例缩放和 cubic-bezier(.22,1,.36,1)；先解码图片，再通知 Main 恢复透明窗口可见度后播放。结束由动画 ACK 收敛到图堆，超时兜底；新截图使旧 presentation/epoch 失效。Reduced Motion 及用户隐藏状态使用小型数量反馈。截图入口先把收纳窗置零透明度、禁用鼠标和焦点，不在首帧路径反复隐藏原生窗口。macOS 快速截图/收纳退出时通过 app.hide 释放前台，再无焦点显示图堆；编辑与贴图保持原焦点路径。显式隐藏仍隐藏原生窗口。关闭/隐藏不清空收纳。

## 连续截图输出状态

框选松手后关闭遮罩，复制/收纳在独立队列执行，不用全屏等待编码。成功状态仍以系统剪贴板提交或 Collection 更新为准。失败沿用现有错误区域，托盘提示待处理/失败；原生菜单提供重试和需确认的放弃。队列满时给出明确错误，不静默丢图。指针选区每 RAF 更新，松手坐标即时计算；不新增页面壳或主题。

原生自排除截图在取帧前激活窗口，用透明度和新会话 ACK 交接旧像素与输入；允许先框选、后等待冻结帧完成输出。Electron fallback 抓图期间禁止晚到 ACK 恢复窗口。原生呈现状态不使用遮挡感知的 isVisible 代替。

## 截图标注与钉图

编辑器沿用现有悬浮工具栏和黑白灰选择框；不改变标注原色。裁剪控制点视觉仍小型，命中区 22 DIP，四条边均可拖动；选中矩形、椭圆或打码后显示方形缩放点。文字工具点击已有文字直接编辑，选择工具双击编辑，保留原图层位置和撤销。

钉图保持透明工作区窗口，图片按原比例展示；悬停或键盘聚焦时在右上显示两个 28 DIP 半透明图标：复制并关闭、关闭。动作区域为 no-drag；图片区域接收双击移除及拖动，边缘仍可原生缩放，不新增面板壳。拖动超过 4 DIP 才移动，拖动产生的双击通知不移除钉图；普通双击仅关闭当前钉图，不删除已保存文件。每张图单独关闭；新截图临时隐藏既有钉图，结束后 showInactive 恢复。未隐藏的钉图获得焦点时不弹设置。实现、验证和平台边界见[修复记录](v2/EDITOR_PIN_FIX.md)。

## 截图后快速切换

Quick 或收纳区单张复制、合并复制、全部复制成功后，可选显示顶部「图标与名称」选择条，属于现有浮动工作区表面，复用 WorkspaceHeader 的语义标题、系统字体和黑白灰 Token，不增加主页面壳。最多 8 个固定目标按用户设置排序；本机应用图标保留原色，macOS 通过原生 AppKit 读取 68px 位图，在 34 DIP 图标位显示；网页优先显示后台读取并本地缓存的网站图标，读取不到时按精确域名回退到 OpenAI / DeepSeek 矢量，其他网页回退到通用图标。设置与浮条共用图标组件；网站图标左下角显示 15 DIP 的浏览器角标：已有标签模式对应 Chrome，普通网页对应系统默认浏览器。角标有中性浅底和细边，保持主图标 34 DIP 与原有按钮尺寸；图片保持原色，矢量继承深浅主题文字颜色，加载失败保留本地回退。后台图标更新只替换当前图标，不重新播放浮条进场、不改变焦点、候选列表、选择状态或倒计时。条位于本次截图或复制来源收纳区所在屏幕工作区顶部中央，透明窗体预留阴影空间；名称 11px，图标 34 DIP，160ms 小幅位移与透明度动画，遵循 Reduced Motion。

默认关闭；设置沿用左说明右控件的分组行，管理启用、显示时间、允许启动未运行应用和添加/移除/排序目标。默认 4 秒，鼠标悬停或键盘选择暂停计时。默认 showInactive，不改变原应用焦点；菜单「选择截图目标」显式进入键盘选择，支持 Tab、左右、Home/End、Enter、Esc。关闭不清除剪贴板。点击条不会打开设置。

第一阶段明确区分「切换应用」和「打开网页」；后者不承诺复用已有标签。第一阶段不自动聚焦第三方聊天输入框、不粘贴、不发送。失败以条内短提示表示，不伪装成功；新截图开始以零透明度和禁用鼠标同步挂起，迟到 ACK 或旧任务不得重新显示。关闭功能销毁该浮层。详细验证见 [第一阶段报告](v2/QUICK_TARGET_PHASE1.md)。


第二阶段为网页目标增加独立的「默认浏览器打开网址 / Chrome 已有标签」选项，沿用设置分组行；自动化与辅助功能分别说明并显式请求。多个匹配时在原浮条下方显示有界滚动列表，提供标题与窗口/标签序号，沿用黑白灰 Token，不新建页面壳。键盘增加上下选择；网页切换成功后立即收起；可选的输入框聚焦未成功时也静默结束，不显示手动点击提示。旧模式继续保留。实现和真实验收边界见[第二阶段记录](v2/QUICK_TARGET_PHASE2.md)。
