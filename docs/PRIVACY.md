# 客户端数据与网络边界

Snipvia 核心无需注册、登录或会员。此说明基于当前源码，不承诺模型厂商或网页服务的保留政策。

## 留在本机的数据

- 模型配置、主题、快捷键和预测分支存于原 Electron userData 下的 `settings.json`；Key 为系统 safeStorage 密文，不通过查询配置接口返回 Renderer。
- 截图及对话存于 `history/`，图片附件存于相应附件目录；日程草稿存于 `schedule/`。授权笔记本目录与 Markdown 文件仍在用户选择的位置，链接记录为 `notebooks.json`。
- Agent 的会话、权限与撤销检查点存于本机对应目录。独立的 `prediction-settings.json` 保存可选 Jev 配置与 safeStorage 密文；不复用聊天模型 Key。旧 `account/session.json` 不再读取、解密或删除，旧账号目录继续受 Agent 文件访问保护。
- 本地优先不等于数据不会落盘。卸载、备份和系统账户迁移会影响这些文件；密文不能保证跨机器或 OS 用户直接解密。没有新增云同步。

## 何时发送内容

用户触发提问、截图预测、日程提取或 Agent 时，Main 向用户配置的模型服务发送该任务需要的输入。启用并保存 Jev Key 后，分支预测改为 Main 直接向 TypeSafe Jev 图片 API 发送裁剪图与分支条件；不经过 Snipvia 后台。未配置/关闭 Jev 时沿用用户视觉模型，已配置 Jev 失败时不自动换服务。截图使用选中的裁剪图；预测只发送启用分支的适用条件，不发送执行 prompt 或 notebookId。后续执行、对话与授权的笔记工具可能向模型发送相关提示词、历史或笔记内容。

模型与接口由用户选择，API 可能计费。自定义服务支持本机 HTTP；远端 HTTP 的 Key 和内容可能明文传输，设置页会提示，旧配置不会被自动重写。优先使用可信的 HTTPS 服务。保存 Key 时 Renderer 处理用户的表单输入，保存后清空；已保存明文 Key 不会通过 IPC 查询返回。

Agent 联网搜索与网页阅读会按工具调用访问 Exa、Brave、DuckDuckGo 或目标网页，不是 Snipvia 账号服务。只有当前任务需要的上下文应进入调用；文件写入仍需授权、差异确认与冲突检查。使用联网能力前应自行评估目标服务的政策。

版本检查访问配置中的 GitHub Release API，不发送模型 Key 或旧账号 Cookie。用户明确下载、重启更新后才进入更新流程；安装更新不依赖官网或登录。模型请求和更新模块不因服务器不可用阻塞本地笔记、历史与截图编辑。

## 测试与排障

默认回归使用临时用户目录和合成图片。真实录屏或旧数据升级验收须先备份、明确测试范围，不公开上传整份用户目录。日志、截图和调试报告在分享前仍需脱敏；不应把模式扫描通过视为隐私审查完成。
