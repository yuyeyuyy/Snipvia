发布日期：2026-10-07。

安装与升级见 [Mac 指南](FRIEND_INSTALL_GUIDE.md)和 [Windows 指南](WINDOWS_FRIEND_INSTALL_GUIDE.md)。Release 同时附中文安装指南、此说明和 `SHA256SUMS.txt`。

## 主要变更

- 加入邮箱验证码登录、云端资格校验。有效体验、订阅或永久资格可使用截图对话；无资格可普通截图，并提示联系管理员。
- AI 截图后可靠打开并聚焦对话窗。空输入 Enter 才触发预测，输入问题直接对话。复制、保存、关闭或取消截图保持主窗口隐藏；点击“返回软件”、Dock 或托盘可手动打开。
- 普通截图增加标注、打码、文字、序号、撤销重做、复制和 PNG 保存。
- 主窗口默认 AI 笔记；文件列表在左，标题大纲在右，支持全屏适配和连续收起。支持 Markdown 三种模式、代码语法高亮与语言复制、GFM 表格、文件 / 文件夹拖拽、附件、Wiki 链接和 ZIP 导出。移除笔记本仅取消链接。
- Agent 可检索并自动整理选定笔记本，实际写入后回复，显示可点击文件变更；工具操作只显示行内状态。macOS 可在笔记本沙箱中运行简短命令和脚本。
- 客户端增加多家模型厂商和接口来源配置，密钥按来源隔离；预测分支名称、适用内容、执行指令及笔记本绑定均可编辑。
- 服务端支持视觉理解 → TypeSafe Jev 预测链路、限额配置和每用户累计请求 / 成功次数。预测错误按阶段脱敏显示，服务端不保存截图和提示词。
- 更新 Mac / Windows 应用图标、Mac Dock 图标和黑白 Retina 菜单栏图标；标题栏集中品牌、账号与设置，主菜单支持连续收起。
- 本地 OCR 使用快速模式提供分支线索，避免准确模式冷启动时的 Neural Engine 初始化阻塞；完整图片理解仍由视觉模型执行。

## 验证与限制

发布检查包括 TypeScript、ESLint、单元测试、使用临时存储与合成截图的 Electron 冒烟、原生辅助程序检查，以及安装包结构、图标和 SHA-256 校验。Windows 完成适配单元测试和 macOS 上的 EXE 交叉构建检查。当前 GitHub 凭据缺少 workflow 权限，未执行真实 Windows runner 安装验收；仓库提供 CI 模板与安装版冒烟测试供后续启用。

本次验证：767 项单元测试通过；23 项桌面集成测试通过，11 项真机 / 特定环境检查跳过；Windows 相关的 61 项适配单元测试通过（包含在上述单元测试内）。Mac 安装包实际启动、隔离 IPC、合成截图复制与安静退出通过；Windows PE 架构、七档图标、NSIS 安装器结构及两平台打包内容检查通过。原生辅助程序的快速 OCR、协议和取消检查通过。

真实多屏、混合 DPI、各类显卡、系统权限界面、安全软件和模型准确率仍需设备验收。Windows 暂不提供 Agent 命令沙箱及系统日历写入；Intel Mac 暂不支持。自动更新、笔记云同步和在线支付尚未实现。

Mac 为临时签名且未 Apple 公证，Windows 未代码签名，安装可能受到系统安全策略限制。

服务端 Docker 版本独立维护；此桌面发行不会自动更新你的服务器。客户端默认账号服务为 `https://console.umbraticus.cn`，对话模型需要用户自己配置 Key，服务端视觉 / Jev Key 由管理员配置。
