# 截然（Snipvia）v0.2.1

发布日期：2026-10-07。此版本在 v0.2.0 基础上更新 Agent 对话、命令确认与笔记撤销。

## 安装与升级

| 平台 | 安装包 | 支持范围 |
| --- | --- | --- |
| macOS | `Snipvia-0.2.1-arm64.dmg` | macOS 14+，Apple 芯片 |
| Windows | `Snipvia-Setup-0.2.1-x64.exe` | Windows 11 x64 |

升级前退出旧版，再替换 / 安装新版。本地设置、历史和笔记目录保留，重要笔记建议先备份。详细步骤见 [Mac 指南](FRIEND_INSTALL_GUIDE.md)和 [Windows 指南](WINDOWS_FRIEND_INSTALL_GUIDE.md)。Release 附中文说明和 `SHA256SUMS.txt`。

## 相比 v0.2.0 的变化

- Agent 会话保存完整工具调用与结果，重开对话或重启应用后可继续上下文；重新选择同一笔记本保留会话，换笔记本或取消绑定时清空对应上下文。删除对话 / 清空历史会同步清理会话文件。
- 长对话根据模型的工作上下文预算自动摘要压缩，校验工具调用与结果配对，控制每轮输出预算，保留已有流式回复。预算估算不等同于厂商账单计量。
- 加入计划清单和逐步执行时间线，展示工具目标、完成状态与耗时；结束后可折叠查看。等待用户确认的命令 / 脚本显示在对话中。
- 脚本和无法静态确认的命令必须获得用户单次批准，按回车不会批准；只读或不覆盖的笔记本整理命令可以直接执行。确认不会扩大 OS 沙箱范围；Windows 仍不开放命令工具。
- 笔记变更支持按轮撤销：确认后恢复编辑、移回文件、删除本轮新建笔记或恢复本轮删除内容。当前文件必须仍与该轮结束时一致，遇到后续修改会拒绝整轮撤销，避免覆盖新内容。停止或失败后的实际修改也可保留检查点。
- 笔记检查点保存差异预览，重启后仍可查看；最多保留 100 份 / 64 MiB。删除对话会清理对应检查点；命令创建的空目录不会随笔记撤销删除。
- 安装说明、Agent 文档和界面示例同步更新；Windows 安装版测试从项目读取版本号，避免固定旧版本。

## 验证与边界

本版在临时构建目录验证，避免覆盖运行中的开发版。发布前检查静态类型、ESLint、单元测试、使用临时账号 / 存储与合成截图的 Electron 集成测试、原生辅助程序，以及两平台安装包内容、图标与 SHA-256。

本次验证：Node 24.15.0 / pnpm 11.1.3；787 项单元测试通过，23 项桌面集成测试通过、11 项真机 / 特定环境检查跳过；静态检查和原生协议 / OCR 检查通过。Mac 安装版实际启动、隔离 IPC、合成截图复制与安静退出通过；Windows PE x64 架构、`0.2.1.0` 版本资源、七档图标与 NSIS 完整性检查通过。

Windows 为 macOS 交叉构建，尚未完成真实 Windows 安装、多屏 / 混合 DPI、显卡和安全软件验收；仓库保留 [Windows CI 模板](ci/README.md)。Mac 仅支持 Apple 芯片，暂不支持 Intel。Mac 使用临时签名且未 Apple 公证；Windows 未代码签名。

Agent 会话与笔记检查点是本地未加密 JSON，包含工具结果和笔记内容，请按私人数据保护其备份。服务端仍只累计预测次数，不留存预测图片或提示词；所选视觉 / 对话厂商接收完成请求所需的内容。

服务端 Docker 版本独立维护，此桌面发行不会更新服务器。账号服务默认 `https://console.umbraticus.cn`；对话模型 Key 由用户配置，视觉 / Jev Key 由管理员配置。自动更新、笔记云同步和在线支付尚未实现。
