# 截然 Snipvia v0.2.2

## 应用内更新

- 启动后在后台检查公开分发仓库的新版本；设置 → 关于也可手动检查。
- 发现新版本时显示版本号与更新说明，由用户点击下载并查看进度。
- 下载完成后，用户选择「重启并更新」；安装前保存当前笔记，并检查是否有进行中的操作。
- 更新下载校验文件哈希与应用签名；客户端无需 GitHub Token。

## 界面与截图

- 统一黑白灰 Light / Dark / System 主题，支持系统外观跟随与窗口间同步。
- 调整日程、笔记、历史、设置及截图 AI 浮窗的布局。
- 优化快捷键截图流程：本地框选不再等待云端账号请求，贴图与 AI 对话按原权限边界处理。
- AI 截图的固定图片只显示截图内容；模型列表使用原始模型 ID。

## 安装与兼容性

- 本次发布 macOS 14+ 的 Apple 芯片（arm64）和 Intel（x64）独立安装包，使用 Developer ID 签名并完成 Apple 公证。
- DMG 用于手动安装，ZIP 供应用内更新使用；发行页同时提供最终 SHA-256 清单。
- 已安装 v0.2.1 或更早版本的用户需要先手动安装 v0.2.2，之后才能使用应用内更新。
- 本次不发布新的 Windows 安装包；已有 Windows 预览版仍采用手动更新。
- Intel 真机、多显示器和混合 DPI 的完整人工验收尚未完成；真实模型请求依赖用户配置的服务与权限。
